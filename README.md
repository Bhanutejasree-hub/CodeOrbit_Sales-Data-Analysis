# Sales Data Analysis

## About the Project
This project focuses on analyzing sales data using Python to understand sales performance and identify useful business insights. The dataset was explored and analyzed using Pandas, and visualizations were created to understand sales trends across different categories, sub-categories, states, and months.

## Objectives
- Analyze overall sales performance.
- Calculate total sales and average order value.
- Identify top-performing product sub-categories.
- Compare sales across product categories and states.
- Understand monthly sales trends using visualizations.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Project Workflow
1. Imported the required Python libraries.
2. Loaded and explored the sales dataset.
3. Checked the data and prepared it for analysis.
4. Calculated total sales and average order value.
5. Analyzed category-wise and sub-category-wise sales.
6. Identified the state with the highest sales.
7. Analyzed monthly sales trends using the Year-Month column.
8. Created visualizations to present the findings.

## Key Findings
- Total sales: 6,182,639
- Average order value: Approximately 11,302.81
- Markers had the highest sales among the sub-categories, followed by Tables and Sofas.
- Office Supplies had the highest sales among the categories.
- New York recorded the highest sales among the states analyzed.
- Monthly sales were analyzed to understand sales trends over time.
